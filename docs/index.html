Architecture

The editor is just I/O

Every completion, chat, and diff review routes through your orchestration daemon. The extension doesn't know — or care — which model answered.

01
VS Code Editor
Continue captures editor context — cursor position, open files, diagnostics — and wraps it as an AO Reach request.
Continue UI
02
AO Reach v0.13.0
WebSocket protocol with optional mTLS. Streams thinking and assistant chunks back as they arrive. Zero buffering.
WebSocket · mTLS
03
COMSTAR Daemon
Model selection, agent routing, MCP tool use, session memory. Runs on your Jetson or any local server. Persistent SQLite KB.
agentic-orchestration

Features

Built for your infrastructure

Designed for developers who run their own AI stack and want their IDE to respect it.

🔒
Private by Design
No code is sent to any cloud service. All routing goes only to the URL in baseUrl. Host on LAN — nothing leaves unless your overlays explicitly call external APIs.
🧠
Persistent Session Memory
The daemon's SQLite knowledge base accumulates codebase context across IDE restarts. Same sessionId means the daemon already knows your repo.
⚡
Streaming First
Thinking and assistant chunks delivered via WebSocket as they arrive. Optional mTLS enrollment for air-gapped or security-sensitive deployments.
📦
Overlay Packs — Editable on Disk
Agent definitions live as YAML files in overlays/. Edit personality, model routing, and tool access without touching extension code.
sessionOverlay: "comstar-code"
sessionOverlay: "comstar-code-review"
🛠
MCP Tool Integration
In-process filesystem tunneling and external MCP servers wired directly to the daemon. The extension doesn't manage tools — the orchestration layer does.
AGENTIC_SERVE_MCP_TUNNEL=1
AGENTIC_SERVE_SESSION_OVERLAY=1
Install

Up in three steps

Clone, build, and point it at your running AO Reach endpoint.

1
Clone & install dependencies
Requires Node.js (version pinned in .nvmrc). No global installs needed.
2
Build the extension
Outputs a .vsix file. Install directly into VS Code, or press F5 for dev mode.
3
Drop in your config
Add a config.yaml pointing at your AO Reach endpoint. Choose an overlay pack. Done.

Requires VS Code 1.85+ and an AO Reach–compatible agentic-orchestration daemon with AGENTIC_SERVE_SESSION_OVERLAY=1.

# Clone the repository
git clone https://github.com/zlatko-lakisic/continue-comstar.git
cd continue-comstar

# Install dependencies (use the pinned Node version)
nvm use
npm install
# Build the .vsix extension package
npm run build

# Option A: install the .vsix directly
code --install-extension continue-comstar-*.vsix

# Option B: launch in development mode
# Press F5 inside VS Code
# config.yaml — workspace root or ~/.continue/
models:
  - title: "COMSTAR"
    provider: comstar
    baseUrl: "http://your-jetson:8000"
    apiKey: "${AO_REACH_TOKEN}"
    sessionOverlay: "comstar-code"
    timeoutSeconds: 30
    streaming: true
    # mtlsMaterialDir: "/path/to/certs"
